# Technical Officer UI — Design Handoff

Open `index.html` directly in Chrome or Edge. It is a single self-contained HTML, CSS and JavaScript prototype with no package dependencies and no external API calls.

The role-oriented interface includes Operations Dashboard, Equipment Handovers, Receive Returns, Inspections, Inventory Catalogue, Stock Operations, Receipt Imports, My Requests, Borrowed Equipment and Activity & History. Navigation and search/filter controls work in the demo. Handover, receipt, inspection and inventory controls open illustrative forms; submitting them shows a prototype notice **without writing data**.

This is a **design and interaction reference**, not a working lending system or official Faculty logo. Any records, counts, policies and people shown are fictional demonstration content. Replace the crest placeholder with the existing approved university logo in the actual application. Do not copy demo data into the application.

`ORBIT-IMPLEMENTATION-DIRECTIVE.md` is the binding implementation brief: use actual official shadcn/ui React components and existing authorized APIs, preserve protected SQL functions and hard security requirements. Follow the HTML composition closely.
